# Ocean RCS publications

For every Ocean deck, proposal, report, overview or one-pager, use the system at
https://github.com/sfield079/ocean-deck-system. Read AGENTS.md and
brand/DESIGN-SYSTEM.md. If repository access is unavailable, use this uploaded
system and the Ocean style guide; never claim to read inaccessible sources.

Use Stack Sans Headline throughout. Install it from Google Fonts when missing.
No silent font substitutions. Embed and verify fonts in PDFs. Use original
Ocean logos without reconstruction, distortion or recoloring.

Default to white pages, Blackmoss text, sparse Sage accents and thin rules.
Keep covers light. Match OceanAshers and OceanOP081926's editorial hierarchy,
removing AI backgrounds, grids and watermarks. Use real photographs in natural
color when useful. No generated decoration, fake icons or oversized card grids.

Use 16:9 editable slides for presentations; Letter/A4 flowing documents for
proposals/reports. Use the correct type scale for each. Split dense content
instead of shrinking or breaking words. Keep evidence editable. The references
establish design, not current verified facts. No invented metrics or promises.

Inspect every rendered page, correct overflow/overlap, verify embedded PDF fonts
and deliver PDF plus editable source. Automated PASS is not visual QA. Do not
add an approval stop when the user has requested a complete build.
